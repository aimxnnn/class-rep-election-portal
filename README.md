# class-rep-election-portal
**DAY 1**

**Problem Statement**
A portal to conduct class representative and student council elections on to ensure fair conduct , students can nominate themselves for a position and then wait for the election officer to approve. Each student can only vote once for one position and the results are showed only after the election is closed.
